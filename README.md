# Eloy Alonso · Portfolio

Este es mi portfolio personal. Soy desarrollador Full Stack y trabajo sobre todo en backend con Laravel, PHP y APIs REST.

## Sobre mí

Llevo más de dos años haciendo backend con PHP, primero con CakePHP y ahora sobre todo con Laravel. Diseño bases de datos MySQL desde cero, las mantengo y, cuando van lentas, averiguo por qué. He trabajado tanto en desarrollos nuevos como en aplicaciones que ya estaban en producción y no se podían parar.

No me ato a un stack. Cuando un proyecto pide algo que no domino, me pongo con ello hasta sacarle partido. Así he acabado usando Node, Python o React Native, y llevando a Android una aplicación de escritorio escrita en TypeScript y Rust.

## Qué hago

- Backend y APIs REST para integrar sistemas sin perder datos por el camino.
- Bases de datos MySQL: diseño, mantenimiento y consultas lentas.
- Mantenimiento y refactorización de código heredado en producción, módulo a módulo.
- CRMs, ERPs y webs a medida.
- Automatización e IA, cuando de verdad ahorran tiempo.
